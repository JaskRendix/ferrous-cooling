# ferrous-cooling

Pure Rust toolkit for Loop Heat Pipe (LHP) analysis, capillary-driven thermal systems, and future two-phase cooling research.

This project began as an implementation of analytical models developed by NASA for spacecraft thermal control. The same physical principles are relevant to modern challenges in AI infrastructure, HPC clusters, advanced semiconductor cooling, power electronics, aerospace platforms, and capillary-driven thermal transport devices.

The goal is to provide a safe, fast, dependency-light engineering library capable of performing first-order thermal and hydraulic calculations without requiring CFD tools or commercial software.

## What Is a Loop Heat Pipe?

A Loop Heat Pipe (LHP) is a two-phase heat transport device that uses capillary pressure generated by a porous wick to circulate working fluid without a mechanical pump.

Heat added at the evaporator vaporizes the fluid.

The generated vapor flows through the vapor transport line and condenser.

The condensed liquid returns through the liquid line and re-enters the evaporator.

The pressure difference required to sustain circulation is supplied by the wick through capillary action.

The operating condition of the system is determined by the balance between:

- capillary pressure
- total hydraulic losses
- phase-change thermodynamics
- compensation chamber behavior
- heat leak mechanisms

## Example

```rust
use ferrous_cooling::{
    Fluid,
    PressureBudget,
    Wick,
    evaluate,
};

fn main() {
    let ammonia = Fluid::ammonia();

    let wick = Wick {
        pore_radius: 1.0e-6,
    };

    let capillary =
        wick.max_capillary_pressure(
            ammonia.surface_tension,
        );

    let result = evaluate(
        capillary,
        PressureBudget {
            groove_loss: 500.0,
            vapor_loss: 2_000.0,
            condenser_loss: 1_000.0,
            liquid_loss: 8_000.0,
            wick_loss: 300.0,
            gravity_loss: 500.0,
        },
    );

    println!(
        "Margin: {:.2}%",
        result.margin_percent
    );
}
```

## CLI

ferrous-cooling also provides a command-line interface for common Loop Heat Pipe calculations.

```bash
# Capillary pressure
ferrous-cooling capillary \
  --surface-tension 0.023 \
  --contact-angle 0.0 \
  --pore-radius 1e-6

# Pressure-budget evaluation
ferrous-cooling budget \
  --capillary-pressure 46000 \
  --groove 500 \
  --vapor 2000 \
  --condenser 1000 \
  --liquid 8000 \
  --wick 300 \
  --gravity 500

# Cold-case inventory
ferrous-cooling inventory cold \
  --rho-liquid 600 \
  --rho-vapor 5 \
  --loop-volume 1e-4 \
  --cc-volume 2e-5 \
  --liquid-fraction 0.8

# Saturation-pressure slope
ferrous-cooling saturation-slope \
  --fluid water \
  --temperature 300
```

Show available commands:

```bash
ferrous-cooling --help
```

Show help for a specific command:

```bash
ferrous-cooling <command> --help
```
